Arquitetura e estratégia

Decisões

Design System com 3 modos

Institucional Claro (site), Escuro Institucional (ferramentas) e Serviços (consultoria). Cada modo tem regras negativas que previnem inconsistência.

App Guidelines encadeadas

Derivadas do Nimbus (Nuvemshop), adaptadas ao EnP. O DS define como parece, as Guidelines definem como se organiza.

IA multi-modelo

Gemini (primário) → Groq (fallback) → Claude (reserva). Quando um cai, o próximo assume sem que o usuário perceba.

Skills como infraestrutura

Conhecimento codificado em .md que a IA lê e aplica - não PDFs que alguém precisa consultar. Versionado, com migration guide.

Magic-link auth

Sem senha pro público interno. Email → link → acesso. Contextos diferentes pedem soluções diferentes.

Vercel pra apps, FTP pra LPs

Apps dinâmicos no Vercel (SSR, crons, APIs). LPs estáticas via FTP. Router A/B em PHP puro.

Infraestrutura antes de produto. Antes de criar LPs, criou um Design System. Antes de criar ferramentas, criou App Guidelines. Antes de escalar, criou a fábrica.

Projetos Destaque

Design System v3.0.0 12 commits

Fundação visual de todo o ecossistema. Especificação completa codificada como skill instalável: tipografia, cores (3 modos cromáticos), spacing, radius, z-index, layout, ícones, logo, gradientes, tabelas, superfícies. Regras negativas por modo. Bootstrap CSS. Checklist pós-build com 14 verificações.

Evolução: v2.0 → v2.1 (ritmo vertical) → v2.3 (logo, wireframes) → v2.4 (inicialização, regras negativas) → v3.0.0 (split core + 5 arquivos) → v3.1.0 (alwaysApply)

Data Intel 100 commits - 11 dias

Plataforma de inteligência de dados que conecta fontes (GA4, Clarity), cruza visão macro com micro e entrega análises via IA. Coleta automaticamente, identifica anomalias, gera briefings com indicadores semânticos e permite conversar via chat.

Stack: Next.js 15, React 19, Drizzle ORM, PostgreSQL (Neon), Gemini + Groq + Claude, Chart.js, Vercel Crons.

Criação EnP 69 + 18 commits

Hub centralizado de criação de ativos visuais com IA. Briefing → IA entende contexto → gera no padrão EnP → pronto. Pivotou entre 4 provedores de IA até achar o melhor (Imagen 4). Login, admin, onboarding, splash animado. Evoluiu de gerador de thumbnails para plataforma multi-produto.

Integração Slack + Cursor PoC

Página criada inteiramente pelo chat do Slack. Alguém escreveu uma mensagem → agente do Cursor baixou a skill do DS → aplicou identidade visual → publicou no GitHub Pages. Ninguém abriu um editor.

Demo: eduardogasparetto-cpu.github.io/slack-cursor-git →

AutoLog Spec pronta

Skill de autodocumentação que analisa padrões de trabalho, registra decisões e propõe melhorias no workflow. Resolve o gap de organização e documentação com automação: documenta automaticamente e pede confirmação.
